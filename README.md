# Цветная метабиблиотека: пересчёт

Сайт: https://ispacex.github.io/metalibrary/ (английская версия), русская — https://ispacex.github.io/metalibrary/ru/

Это пересчёт «хищной спектральной последовательности» из лекции Р. В. Михайлова
«Цветные метабиблиотеки. Разум пространства» (02.09.2016). Считали лист $E^2$ цветной
метабиблиотеки — mod-3 лямбда-алгебру для $S^3$ — и сравнивали его с таблицами Х. Тоды
для 3-кручения $\pi_n(S^2)$.

Здесь только опубликованные результаты: HTML-страницы и данные в `data/` (CSV, JSON).
Страницы собирает генератор из открытого репозитория https://github.com/ispacex/meta-rapacious
(`site/build_site.py`); там же весь код пересчёта, проверялки сертификатов и Lean-проект.
Вручную страницы не правят.

The pages are generated by `site/build_site.py` of https://github.com/ispacex/meta-rapacious,
which also holds all the code of the recomputation, the certificate checkers and the Lean
project. They are not edited by hand.
