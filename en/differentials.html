Differentials of the rapacious rule

The rule as we understood it

$d_r\colon E_r(n,s,c)\to E_r(n-1,\,s+r,\,c+1)$; on each page $r=2,3,\dots$ the maximal rank the dimensions allow is taken. The pages are processed in order.

The grammar gives $\text{stem}=4\sum(\text{indices})-\#\lambda$, that is, $c\equiv \text{stem}+s \pmod 4$. Hence an arrow “colour $+1$” is possible only for $r\equiv2\pmod4$: $d_2, d_6, d_{10},\dots$ The variant “colour $-1$” gives no differentials at all, and in it $\pi_{44}$ keeps four classes, whereas the lecture says it is empty.

Where the rule is ambiguous

On page $r$ the possible arrows line up into chains $x\to y\to z\to\cdots$ with decreasing $n$. The maximal total rank on a chain is determined uniquely, but which classes die is not: a middle class can be either a target or a source. “low” fills a chain starting from the end with the smaller $n$, “high” from the end with the larger.
