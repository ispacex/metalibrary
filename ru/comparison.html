Сравнение по n: правило, Тода, лекция

Строка — группа $\pi_n(S^2)=\pi_n(S^3)$ ($n\ge4$), 3-примарная часть. Число — ранг 3-кручения.

  • E² — нестабильный $E_2$ для $S^3$ при $p=3$ без башни над $\pi_3$, то есть гомологии метабиблиотеки; цвета — $Q$-вес Ext (метод), $n\le150$.
  • хищное — что остаётся после хищного правила с цветом $+1$. Две колонки — два способа заполнять цепочки: «low» и «high» (дифференциалы). Результат окончателен до $n=149$.
  • Тода 2003 — наше прочтение таблицы Тоды 2003 года ($n\le82$); Тода 1962 — его книга ($n\le22$).
Хищное правило («low») совпадает с Тодой при всех $n\le48$. Это ровно стемы $k=n-3<46$, которые Тода определил в 1967 году. Расхождения при $n\le82$: $\pi_{49}$, $\pi_{50}$, $\pi_{51}$, $\pi_{59}$, $\pi_{60}$, $\pi_{63}$, $\pi_{64}$, $\pi_{66}$, $\pi_{67}$, $\pi_{68}$, $\pi_{69}$, $\pi_{70}$, $\pi_{73}$, $\pi_{74}$, $\pi_{75}$, $\pi_{76}$, $\pi_{77}$, $\pi_{79}$, $\pi_{80}$; везде правило оставляет больше классов, чем Тода. Нулей при $49\le n\le149$ правило не даёт ни в одном варианте.
