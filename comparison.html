Сравнение по n: правило, Тода, лекция

Строка — группа $\pi_n(S^2)=\pi_n(S^3)$ ($n\ge4$), 3-примарная часть. Число — ранг 3-кручения.

  • E² — нестабильный $E_2$ для $S^3$ при $p=3$ без башни над $\pi_3$. При $n\le64$ он совпадает с гомологиями метабиблиотеки (наш перебор); дальше, до $n=86$, взят из sseq/ext.
  • хищное — что остаётся после хищного правила с цветом $+1$. Две колонки — два способа заполнять цепочки: «low» и «high» (дифференциалы). Результат окончателен до $n=63$: дифференциалы из $\pi_{65}$ мы ещё не посчитали.
  • Тода 2003 — наше прочтение таблицы Тоды 2003 года; Тода 1962 — его книга ($n\le22$).
Хищное правило («low») совпадает с Тодой при всех $n\le48$. Это ровно стемы $k=n-3<46$, которые Тода определил в 1967 году. Расхождения при $n\le63$: $\pi_{49}$, $\pi_{50}$, $\pi_{51}$, $\pi_{59}$, $\pi_{60}$, $\pi_{63}$; везде правило оставляет больше классов, чем Тода.
